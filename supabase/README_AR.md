# دليل قاعدة بيانات Supabase لمشروع «سجل الفهد»

## 1. الجداول الـ 12 المُنشأة
1. `profiles` — المستخدمون والأدوار (`admin`, `employee`, `aqil`, `representative`) والصلاحيات.
2. `neighborhoods` — الحارات مع بيانات عاقل الحارة.
3. `residential_squares` — المربعات السكنية المرتبطة بكل حارة وبيانات المندوب.
4. `representatives` — سجل تاريخي لتعيينات العقال والمندوبين دون فقدان السجلات السابقة.
5. `people` — السجل الرئيسي للمواطنين (UUID، رقم التعريف، الهوية، الهاتف، السكن، الحالة الصحية، النزوح، اسم المدخل وتاريخ الإدخال).
6. `identity_documents` — صور وثائق الهوية المرتبطة بالمواطنين مع التحقق SHA-256.
7. `aid_programs` — برامج ومشاريع المساعدات والإعانات والجهات المانحة.
8. `aid_beneficiaries` — قائمة المستفيدين المعتمدين لكل برنامج.
9. `aid_distributions` — سجل تسليم واستلام المساعدات مع قيد فريد `(program_id, person_id)` لمنع التكرار غير المقصود.
10. `app_settings` — إعدادات الترويسة الرسمية، شعار النسر، المحافظة والمديرية الافتراضية، وإعدادات الطباعة.
11. `audit_logs` — سجل العمليات الكامل (إضافة، تعديل، حذف، دخول، نسخ احتياطي، تصدير، مزامنة).
12. `sync_metadata` — حالة المزامنة لكل جهاز (`Pending`, `Syncing`, `Synced`, `Failed`, `Conflict`).

## 2. خطوات التفعيل في Supabase
1. أنشئ مشروعاً جديداً في Supabase Dashboard.
2. افتح **SQL Editor** ونفذ محتوى الملف `supabase/migrations/001_sijil_alfahd_schema.sql`.
3. نفذ محتوى الملف `supabase/migrations/002_rls_and_storage.sql`.
4. انسخ **Project URL** و **Anon Key** فقط (لا تستخدم `service_role` أبداً داخل التطبيق) وأدخلهما في شاشة **إعدادات التطبيق** داخل تطبيق «الفهد» لتفعيل المزامنة السحابية التلقائية.
