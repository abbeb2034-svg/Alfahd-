# دليل استخدام نظام «سجل الفهد» (الفهد)

## 1. نظرة عامة
تطبيق **سجل الفهد** (الاسم الظاهر: **الفهد**) هو تطبيق أندرويد أصلي يعمل دون اتصال بالإنترنت (Offline-First) باستخدام قاعدة بيانات SQLite/Room محلية مع دعم المزامنة السحابية مع Supabase عند توفر الاتصال.

## 2. بيانات الدخول
- **اسم مستخدم مدير النظام:** `abbeb34` (بالكلمة المرورية المعتمدة لديكم).
- **حساب الموظف الافتراضي:** `emp1` / `Emp@123`
> يُنصح بإدارة المستخدمين وإعادة تعيين كلمات المرور من شاشة **إدارة المستخدمين والصلاحيات**.

## 3. الصلاحيات
- **المدير:** صلاحيات كاملة (إدارة المستخدمين، إعادة تعيين كلمات المرور، إضافة/تعديل/حذف المواطنين، الحارات والمربعات، المساعدات، الترويسة والشعار، النسخ الاحتياطي والاستعادة، التقارير).
- **الموظف:** عرض البيانات، إضافة مواطن جديد، البحث والتصفية، عرض الكشوفات المسموح بها، **وممنوع من تعديل أو حذف السجلات الموجودة**.

## 4. إضافة مواطن ووثائقه
1. افتح **إضافة مواطن جديد**.
2. اختر **الحارة** أولاً فتظهر **المربعات السكنية التابعة لها فقط**.
3. أدخل بيانات المواطن والأسرة والسكن والحالة الصحية والنزوح.
4. اختر نوع الوثيقة:
   - **الهوية الوطنية:** صورتان (الوجه الأمامي والخلفي).
   - **جواز السفر / الاستبيان / البطاقة العائلية / رقم الجلوس / البطاقة التعريفية:** صورة واحدة.
5. يتم الحفظ فوراً محلياً وتُضاف العملية إلى طابور المزامنة (`Pending`) وسجل العمليات.

## 5. الكشوفات والتقارير الرسمية (PDF وExcel)
- يدعم 13 نوعاً من الكشوفات مع إمكانية اختيار الأعمدة واتجاه الورق (عمودي/أفقي A4).
- **PDF:** ترويسة رسمية متكررة في أعلى كل صفحة + عناوين أعمدة متكررة + جدول مسطر + ترقيم `الصفحة X من Y`.
- **Excel (.xlsx):** ورقة RTL مسطرة بالكامل + ترويسة مدمجة + `Print_Titles` لتكرار الترويسة وعناوين الأعمدة عند الطباعة + خلايا قابلة للتعديل.

## 6. ربط Supabase
1. نفّذ الملفين `supabase/migrations/001_sijil_alfahd_schema.sql` و`002_rls_and_storage.sql` في **Supabase SQL Editor**.
2. من داخل التطبيق افتح **إعدادات التطبيق** وأدخل `Project URL` و`Anon Key` فقط (لا تضع `service_role` أبداً).
